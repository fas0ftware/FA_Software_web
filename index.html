Selected work

A home-network security set built from the ground up — a scanner in C, a decoy that wastes attackers' time, and a monitor that tells you what to fix — plus a market dashboard.

Version 2.1Network security

Home Network Monitor

Knows every device on your Wi-Fi, checks each one for open ports and pushes an alert to your phone when something new shows up. Then it tells you what to do about it.

  • Security advisor: risk level, explanation and step-by-step fix for 29 ports
  • Security score and a "fix these first" list
  • Hardened dashboard: token, CSP, CSRF and DNS-rebinding guards

Python · Scapy · SQLite · Flask · JavaScript

Version 0.3.1Honeypot

Maze

A fake login page in layers. Attackers find "passwords" that lead deeper, every answer gets slower, and every move is logged. Nobody at home has a reason to log in, so every attempt is a signal.

  • C engine with Argon2id and constant-time checks (no timing leaks)
  • Minator: a passive report of who tried what, and how long they were kept busy
  • Non-root, read-only Docker image behind a production WSGI server

C · libsodium · Python · Flask · Docker

View on GitHub ↗

Version 1.5Port scanner

Janus

A dependency-free port scanner written in C. One pool of worker threads covers every host at once, so a silent subnet costs one timeout instead of hundreds.

  • TCP and UDP, host discovery without root, IPv4/IPv6, CIDR blocks
  • Sanitized banners and JSON output for other tools
  • Clean under ASan, UBSan, ThreadSanitizer, valgrind and cppcheck

C11 · POSIX sockets · pthreads

View on GitHub ↗

Version 2.0Data & finance

Heimdall

Turns raw market data into signals, risk numbers and "what if" simulations for any Yahoo Finance symbol: US stocks, Borsa Istanbul, crypto, FX and futures.

  • Candlesticks, RSI, MACD, golden and death crosses, Bollinger Bands
  • Time Machine: lump sum versus monthly investing
  • 35 tests, including headless UI tests of every tab

Python · pandas · Streamlit · Plotly
